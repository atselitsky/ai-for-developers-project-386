# AGENTS.md

## Структура проекта

Монорепозиторий (Yarn workspaces) для сервиса бронирований (аналог Cal.com):

- `packages/typespec/` — TypeSpec спецификация API → генерирует OpenAPI 3.1.0
- `packages/frontend/` — Vue 3 приложение
- `cmd/server/` — Go бэкенд

## Команды

```bash
# Сборка TypeSpec
yarn build:typespec
```

## Общие правила

- Исправляй причину, а не следствие
- Если видишь изменения, которые ты не делал, игнорируй их

## Правила API

- Длительность встреч: кратно 15 минутам (15–480)
- Окно бронирования: 14 дней от текущего момента
- Рабочие часы: 09:00–18:00 UTC, пн–пт
- Пересечения бронирований запрещены (409 Conflict)
- Нельзя удалить EventType с активными бронированиями (409)
- Авторизация: требуется заголовок `X-API-Key`

## Генерируемые TypeSpec артефакты

Запись в эти папки typespec запрещена (могут редактироваться только утилитами typespec):
- `packages/typespec/tsp-output/` — результат сборки TypeSpec
- `packages/frontend/src/api/` — будущий сгенерированный клиент
- `cmd/server/internal/generated/` — будущий сгенерированный Go код
