# Тестирование фронтенда

## Пирамида тестов

1. **Unit** (Vitest) — чистые функции без DOM: валидаторы, генерация слотов (`src/mocks/slots.ts` как пример).
2. **Component** (Vitest + `@vue/test-utils`) — монтирование Vue-компонентов, взаимодействие как у пользователя (клики, ввод), без мока дочерних компонентов. Проверяем props/events/slots и видимый результат, а не приватное состояние.
3. **E2E** (не подключено; кандидат — Playwright) — добавляется позже, когда появится рабочий бэкенд, для 2–3 сквозных сценариев (бронирование гостем, создание типа события владельцем).

Источники: [Vue.js Testing Guide](https://vuejs.org/guide/scaling-up/testing.html), [Vitest Guide](https://vitest.dev/guide/), [Playwright Best Practices](https://playwright.dev/docs/best-practices).

## Конвенции

- Файлы тестов — `*.spec.ts` в `__tests__/` рядом с тестируемым кодом.
- Селекторы — `getByRole`/`getByText`/`data-testid`, не CSS-классы.
- Даты/время — `vi.useFakeTimers()` / явный параметр `now` в функциях (см. `generateSlots`), чтобы тесты были детерминированными.
- Component-тесты не мокают дочерние компоненты.

## Контрактные моки (MSW)

Схема данных генерируется из TypeSpec-контракта, а не пишется руками:

```
packages/typespec/*.tsp → yarn generate:api → OpenAPI 3.1 → openapi-typescript → packages/frontend/src/api/schema.ts
```

- `src/api/` — **только сгенерированный код**, руками не редактируется (см. `AGENTS.md`). Перегенерируется автоматически перед `test`/`type-check`/`dev`/`build` (хуки `pretest`, `pretype-check`, `predev`, `prebuild`).
- `src/mocks/handlers.ts` — MSW-хендлеры на все эндпоинты `EventTypes`, `Bookings`, `TimeSlots`, типизированные через `components['schemas']` из `src/api/schema.ts`.
- `src/mocks/fixtures.ts` — in-memory хранилище, сбрасывается перед каждым тестом (`resetFixtures()` в `src/mocks/setup.ts`).
- `src/mocks/slots.ts` — бизнес-правила окна записи (14 дней, Пн–Пт 09:00–18:00 UTC, кратность 15 минутам) как чистые функции с собственными unit-тестами.
- Подключение в Vitest — `setupFiles: ['./src/mocks/setup.ts']` в `vite.config.ts`.

### Допущения, не заданные явно в `operations.tsp`

Эти коды ответа выведены из `README.md`/`AGENTS.md`, а не из типизированных responses конкретных операций. При появлении реального Go-бэкенда — сверить и при расхождении поправить `src/mocks/handlers.ts`:

| Ситуация | Код в моках | Основание |
|---|---|---|
| Нет заголовка `X-API-Key` | `401` | Глобальный `security: [ApiKeyAuth]` в OpenAPI, явно упомянут в `AGENTS.md`/`README.md` |
| Длительность события не кратна 15 / вне 15–480 | `400` | Бизнес-правило из `README.md`, не типизировано для `EventTypes.create/update` (там только `200/404/409`) |

## Команды

- `yarn test` — запуск тестов (Vitest).
- `yarn test:coverage` — запуск с покрытием (`@vitest/coverage-v8`).
- `yarn generate:api` — пересобрать TypeSpec → сгенерировать типы в `src/api/schema.ts`.

## Что не покрываем сейчас

`App.vue`, `router/index.ts`, `HomeView.vue` — временный каркас, будет заменён реальными вьюхами. Тесты пишем вместе с реальными фичами.

## Чек-лист тестов по будущим фичам

| Область | Тип теста | Что проверять |
|---|---|---|
| Валидация типа события (title/description/duration) | Unit | Кратность 15, диапазон 15–480, обязательные поля |
| CRUD типов событий (админка) | Component | Рендер списка по данным API, создание/редактирование/удаление, 409 при удалении с активными бронями |
| Список видов брони (гость) | Component | Название/описание/длительность, пустое состояние, ошибка загрузки |
| Календарь / выбор слота | Unit + Component | Генерация слотов (уже покрыто `slots.spec.ts`), недоступность занятых/прошедших слотов, клик по свободному слоту |
| Форма бронирования | Component | Успешный сабмит → подтверждение; обработка 409/422 с понятным сообщением; клиентская валидация email/имени |
| Список предстоящих встреч (владелец) | Component | Агрегация всех типов событий, сортировка по времени, отмена бронирования |
| Сквозной сценарий бронирования | E2E (после появления бэкенда) | Гость выбирает тип → слот → создаёт бронь → слот пропадает из доступных |
